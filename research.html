RESEARCH

Research directions

Developing accurate, interpretable, and scalable methods for graph intelligence.

01

Big Graph Analytics

Scalable analysis of large networks using distributed data-processing frameworks, with an emphasis on efficient graph computation.

02

Link Prediction

Prediction of potential or missing links using local similarity indices, centrality measures, node influence, and representation learning.

03

Graph Neural Networks

Learning graph representations with architectures such as GCN, GAT, GraphSAGE, autoencoder-based models, and specialized link-prediction networks.

04

Distributed Graph Processing

Exploring Apache Spark and HDFS for parallel and distributed link prediction on larger network datasets.

Current direction

Distributed Centrality-Aware Link Prediction Framework for Large-Scale Networks Using Apache Spark.
